# Contributing

Contributions should improve repeatability, clarity, or output quality without copying a living artist, copyrighted character, identifiable person, brand system, or source composition.

For a new or changed Skill:

1. Keep `SKILL.md` concise and provider-agnostic.
2. Put detailed style rules in `references/style-guide.md`.
3. Include original example outputs only.
4. Add explicit failure signals and negative constraints.
5. Run `node scripts/validate-skills.mjs`.
6. Test the Skill on at least three different article ideas.
