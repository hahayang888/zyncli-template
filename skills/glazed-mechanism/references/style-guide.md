# Glazed Mechanism style guide

## Visual DNA

Approachable systems illustration built from hand-formed glazed ceramic gates, vessels, channels, and joints that perform one mechanically clear workflow.

- Aspect ratio: 16:9 horizontal
- Canvas: warm matte studio base with a shallow horizon, soft daylight, and enough space to inspect the mechanism
- Rendering language: glaze pooling, hand-built irregularity, rounded ceramic edges, real contact shadows, and physically connected modules
- Minimum whitespace: 25%
- Maximum subject coverage: 71%
- Typography: No text by default; at most four supplied one-word labels impressed clearly into separate ceramic tags.

## Palette

| Role | Color | Use |

| Palette 1 | `#31588B` | primary structure and focal subject |
| Palette 2 | `#C9654B` | supporting contrast and secondary forms |
| Palette 3 | `#D5AE63` | accent for emphasis and directional cues |
| Palette 4 | `#E6DED0` | restrained supporting accent |

## Must

- mechanism can operate physically
- input and output are distinct
- glaze variation remains controlled
- one active transformation
- modules visibly connect

## Never

- cute pottery set
- toy machine
- decorative vases
- floating modules
- plastic 3D
- kitchenware advertisement

## Negative constraints

- no logo
- no headline
- no faces
- no glossy plastic
- no random ceramic ornaments
- no impossible levitation

## Composition patterns

### Focal metaphor

Best for: core argument, abstract concept.

Build one dominant physical metaphor around the article's central relationship.

### Contrast

Best for: before and after, tradeoff, tension.

Use two clearly different states joined by one meaningful transition.

### Process

Best for: workflow, cause and effect, transformation.

Show only the essential stages and make the change itself visually dominant.

### System relationship

Best for: framework, network, components.

Limit the system to three to five meaningful parts with an obvious hierarchy.

### Narrative scene

Best for: human consequence, decision, editorial tension.

Stage one decisive moment rather than summarizing the whole article.

## Metaphor method

1. Translate the abstract relationship into a physical arrangement.
2. Choose one object family suited to the visual medium.
3. Make the decisive change visible without relying on a headline.

Object pool:

- ceramic gate
- glazed channel
- sorting vessel
- hinged tile
- fired valve
- modular kiln
- transfer ramp
- collection basin

Action pool:

- route
- filter
- pour
- sort
- open
- transfer
- combine
- release

Anti-repetition:

- Change both the main object and the spatial arrangement between illustrations.
- Do not repeat the same composition pattern consecutively.
- Derive metaphors from the current article rather than a stock visual library.

## QA checklist

- workflow is traceable
- ceramic material is convincing
- connections are physical
- one transformation dominates
- scene remains editorial

Failure signals:

- looks like tableware
- mechanism cannot work
- too many decorative pieces
- material reads as plastic
- input and output are unclear
