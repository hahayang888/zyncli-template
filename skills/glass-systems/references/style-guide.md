# Glass Systems style guide

## Visual DNA

Premium conceptual 3D systems built from physically plausible optical glass, brushed metal, translucent channels, and restrained spectral light, with one visible transformation or routing relationship.

- Aspect ratio: 16:9 horizontal
- Canvas: deep slate or pale mineral studio field with a single engineered structure, coherent ground or suspension logic, and ample quiet space
- Rendering language: physically based glass and metal rendering, precise refraction, subtle caustics, brushed microtexture, restrained violet-cyan light, and crisp depth separation
- Minimum whitespace: 28%
- Maximum subject coverage: 68%
- Typography: No text, numbers, labels, interface marks, control icons, logos, or pseudo-writing.

## Must

- one understandable system relationship
- physically coherent refraction
- restrained material palette
- visible input and output
- premium editorial lighting
- clear silhouette at thumbnail size

## Never

- generic glass orb
- floating blob collection
- crypto artwork
- neon cyberpunk
- product advertisement
- UI glassmorphism
- rainbow refraction everywhere
- impossible glass intersections

## Negative constraints

- no text
- no logo
- no UI
- no device mockup
- no cyberpunk city
- no excessive bloom
- no floating decorative spheres
- no humanoid robot
- no rainbow overload

## Composition patterns

### Focal metaphor

Best for: core argument, abstract concept.

Build one dominant physical metaphor around the article's central relationship.

### Contrast

Best for: before and after, tradeoff, tension.

Use two clearly different states joined by one meaningful transition.

### Process

Best for: workflow, cause and effect, transformation.

Show only the essential stages and make the change itself visually dominant.

### System relationship

Best for: framework, network, components.

Limit the system to three to five meaningful parts with an obvious hierarchy.

### Narrative scene

Best for: human consequence, decision, editorial tension.

Stage one decisive moment rather than summarizing the whole article.

## Metaphor method

1. Translate the abstract relationship into a physical arrangement.
2. Choose one object family suited to the visual medium.
3. Make the decisive change visible without relying on a headline.

Object pool:

- optical gate
- refractive channel
- glass manifold
- metallic lens
- layered prism
- transparent chamber
- signal conduit
- precision hinge

Action pool:

- route
- split
- focus
- filter
- recombine
- transform
- amplify
- align

Anti-repetition:

- Change both the main object and the spatial arrangement between illustrations.
- Do not repeat the same composition pattern consecutively.
- Derive metaphors from the current article rather than a stock visual library.

## QA checklist

- system function reads without labels
- glass has plausible thickness and refraction
- spectral color remains restrained
- materials separate clearly
- composition feels editorial
- no generic tech-render clichés

Failure signals:

- decorative glass shapes with no idea
- excessive neon
- looks like a phone wallpaper
- refraction obscures the system
- generic crypto aesthetic
- glossy product-ad lighting
