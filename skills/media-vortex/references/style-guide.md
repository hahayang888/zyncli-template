# Media Vortex style guide

## Visual DNA

Dark painterly editorial realism using circular information flow, tactile blank media forms, deep navy and umber atmosphere, amber highlights, and one human act of selection.

- Aspect ratio: 16:9 horizontal
- Canvas: immersive dark archive or abstract chamber with one quiet center, controlled circular movement, and strong light hierarchy
- Rendering language: visible painterly brush texture, tactile analog object surfaces, restrained cool-cyan secondary light, warm amber focus, and conceptual rather than photographic detail
- Minimum whitespace: 20%
- Maximum subject coverage: 76%
- Typography: Every media surface remains blank; no titles, publication text, interface copy, symbols, or pseudo-writing.

## Must

- one circular information flow
- one human decision
- one quiet focal center
- original blank media forms
- warm-versus-cool light hierarchy
- tactile painterly depth

## Never

- branded device
- smartphone
- television
- newspaper
- comic panel
- currency symbol
- social-media icon
- humanoid AI
- cyberpunk neon
- decorative nostalgia

## Negative constraints

- no text
- no pseudo-writing
- no logo
- no brand
- no UI panel
- no humanoid AI
- no recognizable publication
- no social icon
- no neon spectacle

## Composition patterns

### Focal metaphor

Best for: core argument, abstract concept.

Build one dominant physical metaphor around the article's central relationship.

### Contrast

Best for: before and after, tradeoff, tension.

Use two clearly different states joined by one meaningful transition.

### Process

Best for: workflow, cause and effect, transformation.

Show only the essential stages and make the change itself visually dominant.

### System relationship

Best for: framework, network, components.

Limit the system to three to five meaningful parts with an obvious hierarchy.

### Narrative scene

Best for: human consequence, decision, editorial tension.

Stage one decisive moment rather than summarizing the whole article.

## Metaphor method

1. Translate the abstract relationship into a physical arrangement.
2. Choose one object family suited to the visual medium.
3. Make the decisive change visible without relying on a headline.

Object pool:

- archive ring
- blank image tiles
- unlabeled discs
- media ribbons
- memory table
- layered panels
- attention chamber
- signal fragments

Action pool:

- select
- circulate
- filter
- archive
- retrieve
- amplify
- discard
- reframe

Anti-repetition:

- Change both the main object and the spatial arrangement between illustrations.
- Do not repeat the same composition pattern consecutively.
- Derive metaphors from the current article rather than a stock visual library.

## QA checklist

- circular flow remains readable
- human choice is the focal action
- surfaces are blank
- lighting carries hierarchy
- objects feel original and unbranded
- scene avoids cyberpunk and nostalgia clichés

Failure signals:

- humanoid AI appears
- recognizable devices dominate
- media surfaces contain text
- vortex becomes decorative spectacle
- scene looks like sci-fi key art
- too many unrelated objects
