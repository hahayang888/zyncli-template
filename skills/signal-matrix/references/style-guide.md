# Signal Matrix style guide

## Visual DNA

Sophisticated technology editorial collage combining one legible system metaphor, luminous cobalt structures, restrained cyan signal paths, and tactile digital artifacts.

- Aspect ratio: 16:9 horizontal
- Canvas: deep indigo-to-near-black field or pale technical paper field, with one illuminated spatial zone; use subtle scan grain and sparse matrix marks only where they explain structure
- Rendering language: precise modular geometry mixed with selective scanned edges, halftone fragments, thin signal paths, and crisp depth separation
- Minimum whitespace: 27%
- Maximum subject coverage: 68%
- Typography: No headline, code paragraph, or fake interface text. At most three tiny functional identifiers made of real short words or numbers.

## Must

- one concrete system relationship
- a dominant engineered structure or symbolic machine
- controlled cobalt, ultraviolet, and cyan light
- clear depth with foreground, system core, and quiet field
- editorial intelligence rather than spectacle
- texture that supports the concept

## Never

- generic glowing brain
- hooded hacker
- floating dashboard panels
- robot handshake
- cyberpunk city
- random circuit-board background
- illegible code
- technology product advertisement

## Negative constraints

- no brand logos
- no fake UI screenshot
- no stock 3D robot
- no neon rainbow
- no lens-flare spectacle
- no dense binary wallpaper
- no text blocks
- all archive surfaces use abstract lines and shapes, never letter-like marks
- no humanoid AI face

## Composition patterns

### Focal metaphor

Best for: core argument, abstract concept.

Build one dominant physical metaphor around the article's central relationship.

### Contrast

Best for: before and after, tradeoff, tension.

Use two clearly different states joined by one meaningful transition.

### Process

Best for: workflow, cause and effect, transformation.

Show only the essential stages and make the change itself visually dominant.

### System relationship

Best for: framework, network, components.

Limit the system to three to five meaningful parts with an obvious hierarchy.

### Narrative scene

Best for: human consequence, decision, editorial tension.

Stage one decisive moment rather than summarizing the whole article.

## Metaphor method

1. Translate the abstract relationship into a physical arrangement.
2. Choose one object family suited to the visual medium.
3. Make the decisive change visible without relying on a headline.

Object pool:

- signal lattice
- data prism
- modular core
- transparent conduit
- routing gate
- layered archive
- sensor field
- distributed nodes
- fault line
- compression chamber

Action pool:

- route
- decode
- compress
- train
- filter
- synchronize
- partition
- protect
- amplify
- reconstruct

Anti-repetition:

- Change both the main object and the spatial arrangement between illustrations.
- Do not repeat the same composition pattern consecutively.
- Derive metaphors from the current article rather than a stock visual library.

## QA checklist

- technology concept is specific rather than generic
- system hierarchy is immediately legible
- digital texture remains subordinate
- lighting reveals the relationship
- no fake interface or unreadable text
- works at article-column width

Failure signals:

- looks like a sci-fi movie poster
- generic AI symbolism
- too many glowing elements
- flat decorative circuit pattern
- unreadable microtext
- letter-like marks appear on archive surfaces
- no clear system relationship
