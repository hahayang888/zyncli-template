# Felted Logic style guide

## Visual DNA

A tactile textile explainer made from cut wool felt, embroidered junctions, and tensioned threads that physically construct a network or decision system.

- Aspect ratio: 16:9 horizontal
- Canvas: neutral woven cloth field or shallow tabletop with visible fiber, gentle contact shadow, and generous margins
- Rendering language: soft felt edges, honest stitched seams, thread tension, layered thickness, and deliberately limited hand-cut geometry
- Minimum whitespace: 27%
- Maximum subject coverage: 69%
- Typography: Avoid words; if essential, use only supplied one-word labels embroidered clearly outside junctions.

## Palette

| Role | Color | Use |
| --- | --- | --- |
| Palette 1 | `#273D87` | primary structure and focal subject |
| Palette 2 | `#D45F4B` | supporting contrast and secondary forms |
| Palette 3 | `#D5A846` | accent for emphasis and directional cues |
| Palette 4 | `#E9E2D4` | restrained supporting accent |

## Must

- every thread has a functional endpoint
- material thickness is visible
- one dominant path
- handmade variation
- clear node hierarchy

## Never

- decorative quilting
- cute nursery craft
- knitted mascot
- random yarn tangle
- flat vector simulation
- ornamental floral embroidery

## Negative constraints

- no logo
- no headline
- no fake lettering
- no plastic fibers
- no rainbow yarn
- no disconnected decorative stitches

## Composition patterns

### Focal metaphor

Best for: core argument, abstract concept.

Build one dominant physical metaphor around the article's central relationship.

### Contrast

Best for: before and after, tradeoff, tension.

Use two clearly different states joined by one meaningful transition.

### Process

Best for: workflow, cause and effect, transformation.

Show only the essential stages and make the change itself visually dominant.

### System relationship

Best for: framework, network, components.

Limit the system to three to five meaningful parts with an obvious hierarchy.

### Narrative scene

Best for: human consequence, decision, editorial tension.

Stage one decisive moment rather than summarizing the whole article.

## Metaphor method

1. Translate the abstract relationship into a physical arrangement.
2. Choose one object family suited to the visual medium.
3. Make the decisive change visible without relying on a headline.

Object pool:

- stitched network
- felt junction
- thread bridge
- layered map
- woven gate
- patched route
- tensioned loop
- shared seam

Action pool:

- stitch
- route
- join
- branch
- mend
- tighten
- weave
- untangle

Anti-repetition:

- Change both the main object and the spatial arrangement between illustrations.
- Do not repeat the same composition pattern consecutively.
- Derive metaphors from the current article rather than a stock visual library.

## QA checklist

- connections are structurally believable
- fiber reads as real
- route is immediate
- craft supports explanation
- palette remains disciplined

Failure signals:

- looks like children's craft
- thread endpoints are meaningless
- too many colors
- system hierarchy disappears
- material looks digitally flat
